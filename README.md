# ElectroStore
Descripción del proyecto

ElectroStore es una tienda virtual desarrollada como proyecto académico utilizando HTML, CSS, JavaScript y Bootstrap. El sitio permite visualizar productos tecnológicos, agregar artículos al carrito de compras, realizar simulaciones de compra y generar una factura al finalizar el proceso.

El objetivo principal del proyecto es aplicar los conocimientos adquiridos en desarrollo web, diseño responsivo y programación con JavaScript.
